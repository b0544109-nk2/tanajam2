# TANAHASHI JAM 2 観戦しおり

2026年11月19日（木）後楽園ホール『TANAHASHI JAM 2 by CSテレ朝チャンネル』の、身内向け観戦しおりです。

- ページ本体：`index.html`（1ファイルで完結）
- 画像：`images/` フォルダに入れると自動で表示されます

## 画像の入れ方

1. GitHubでこのリポジトリを開いて、`images` フォルダに入る
2. 「Add file」→「Upload files」で画像をアップロード（スマホのブラウザからでもOK）
3. **ファイル名を下の表のとおりにする**（例：大岩陵平なら `oiwa.jpg`）
4. 「Commit changes」を押す → 1〜2分でページに反映されます

**ルール**

- 拡張子は `.jpg` / `.jpeg` / `.png` / `.webp` のどれでもOK（同じ名前で複数入れたら `.jpg` が優先）
- ファイル名は**半角小文字**。大文字や全角が混ざると表示されません
- 差し替えたいときは、同じ名前でアップロードし直す（上書きされます）
- 外したいときは、そのファイルを削除する（イニシャル表示に戻ります）
- 1枚あたり1MB以下くらいが目安（大きいとスマホで表示が遅くなります）
- 反映されないときは、ページを再読み込み（キャッシュで古い表示が残ることがあります）

## タブや選手へ直接飛ぶURL

URLの最後に `#タブ名` を付けると、そのタブが開いた状態で表示されます（`?tab=タブ名` でもOK）。
